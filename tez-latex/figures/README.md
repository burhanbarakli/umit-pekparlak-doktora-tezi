# Şekiller

Yeni veya yeniden üretilen şekilleri bu klasöre koyun. Tercih sırası:

1. PDF veya SVG'den üretilmiş PDF vektör şekil,
2. en az 300 dpi PNG,
3. yalnızca fotoğraflar için yüksek kaliteli JPEG.

Dosya adlarında boşluk ve Türkçe karakter kullanmayın. Örnek: `genel_sistem_blok_diyagrami.pdf`.
